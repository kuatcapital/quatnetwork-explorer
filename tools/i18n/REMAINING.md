Дата сверки: 02.11.2026. Все десять шагов, включая Dynamic, опубликованы в `0b87bd2`. Итоги — `PHASE9-HANDOFF.md`, `PHASE10-HANDOFF.md`.

**По решению владельца от 01.11.2026 сохраняем всё уже переведённое и завершаем обычный просмотр транзакций, адресов, балансов и токенов на RU/KK.** Оставшиеся сложные инструменты допустимы на английском и больше не задерживают завершение T18. Не откатывать готовые переводы, не вводить принудительный EN, не скрывать функции и не разрабатывать отдельный «простой режим».

Уточнение владельца от 28.10.2026: оставшаяся локализация и языковая приёмка — только RU/KK. Английский уже исходный язык эксплорера: отдельно его не переводить, не редактировать и не проверять обходом экранов. Существующий EN и переключатель сохраняются; общие проверки кода, структуры словарей и сборки остаются обязательными.

## 1. Собственные экраны

- Шаг8 закрыл toasts добавления сети/наград/собственной ошибки Dynamic, cluster search placeholder, Native token display и known unfinalized status. Исправлены четыре сравнения API-типа с переводом в двух portfolio-компонентах; machine ids снова стабильны. Эти места заново не извлекать.
- Шаг9 подключил поддержанные accessibility translations/aria в PinInput, Rating, Progress/ProgressCircle, Select, Popover и Toaster. Проверены caller overrides, сохранение отредактированных значений и фокуса при RU ↔ KK, прежние горячие клавиши; подробности в `PHASE9-HANDOFF.md`.

- Готовые переводы продвинутых страниц, 34 showcase-компонентов и Dynamic сохраняются. Их полный браузерный обход больше не является обязательным критерием языковой приёмки T18.
- Проверить подписи, сообщения и aria-label на обычном пользовательском пути из §3. Исправлять обнаруженные там пропуски RU/KK; общий поиск новых переводов во всех production-разделах не продолжать.
- check-locales отмечает 94 динамические ссылки `t(...)`; это техническая инвентаризация, не 94 обязательные новые задачи. Регрессионные проверки сохраняются, ручная сверка ограничена обычным сценарием. Отсутствие literal-missing errors не заменяет браузерную приёмку.

Прямой DOM-подменой текстов и отключением функций проблему не закрывать. Не обновлять GPL frontend на другую лицензию ради готового перевода.

Полный обход реальных модальных сценариев кошелька не обязателен для приёмки обычного просмотра транзакций: просмотр не требует подключения кошелька. Технические наблюдения в `EXTERNAL-UI-NOTES.md` — справка, а не очередь обязательных переводов.

## 3. Приёмка и доставка

1. Браузерный обход RU/KK на desktop/mobile по чек-листу ниже; отдельный обход и вычитка EN исключены владельцем. Полный аудит всех feature flags и сложных разделов не требуется.
2. Проверить реальную замену runtime JSON без пересборки и поведение при недоступном/повреждённом словаре. Unit-тесты есть, browser smoke ещё нет.
3. Казахский текст обычного сценария отдать носителю; машинные идентификаторы, ABI, пользовательский контент и raw API не переводить.
4. Docker build ранее отложен владельцем. Без него сборочный критерий T18 не закрыт. Серверы не использовать как обход.
5. Основной репозиторий: после проверки сборки заменить baseline SHA `42add5f...` в `scripts/explorer.sh`, завершить переход от старого overlay. Затем два PR: frontend в `claude/gpl-v2.7.2`, интеграция в `claude/besu-testnet`; мерджит владелец.

Чек-лист обычного сценария (браузерная приёмка ещё не выполнена):

- [ ] Главная → поиск по хешу транзакции или адресу → результат; корректное пустое состояние.
- [ ] Список и карточка обычной транзакции: статус, сумма, токен, отправитель, получатель, дата, комиссия, блок и копирование хеша/адреса.
- [ ] Адрес: баланс, токены, история; переходы к базовым страницам токена и блока.
- [ ] Пагинация, загрузка и ошибки; длинные RU/KK строки, числа, даты и множественное число на desktop/mobile.
- [ ] Переключение RU ↔ KK и сохранение языка после обновления; просмотр без подключения кошелька.

Unit-тесты не закрывают эти пункты автоматически. Исправлять только подтверждённые проблемы обязательного сценария, сохраняя готовые переводы остальных разделов.
